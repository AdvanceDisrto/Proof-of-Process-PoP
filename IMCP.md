# iMCP — i™ Authority Layer Over MCP

iMCP governs MCP traffic without replacing MCP transport or standard JSON-RPC semantics.

- MCP owns transport and standard capability/method negotiation.
- iSKA owns caller identity and delegation.
- i™ owns intent sealing, one-use challenges, and process receipts.
- Reality Ledger owns receipt persistence.
- Independent vendor verification is the only authority capable of establishing physical truth.

Every standard MCP execution requires a valid iSKA delegation and one-use iMCP challenge nonce. Successful tool output never promotes physical_gate; iMCP receipts remain ACTION_REQUIRED.
