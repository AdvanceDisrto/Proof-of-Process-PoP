# Novel Process-of-Truth Frontiers

These additions extend PoP with new evidence dimensions while preserving the
truth ladder. They are software evidence primitives, not claims of deployed
blockchain economics, production ZK proving, physical drones, or biological
storage.

| Frontier | Implemented boundary | Not claimed |
|---|---|---|
| Epistemic Economy | deterministic stake/slash adjudication | on-chain staking, custody, or settlement |
| zk-TEE | model/input/output/attestation commitments | production ZK proof or real TEE quote |
| Swarm Actuator | independent-observer quorum | real drone deployment or sensor accuracy |
| DNA Archive | reversible digest-to-DNA encoding | physical synthesis, vault storage, or durability |
| Genesis Seed | offline local receipt with later anchor transition | global consensus while disconnected |

The common invariant is fail-closed evidence escalation: a simulation cannot
promote itself into physical fact. The Genesis Seed is the convergence point:
an offline node can preserve a commitment and local quorum state, then later
transition only when an actual external anchor receipt is supplied.
