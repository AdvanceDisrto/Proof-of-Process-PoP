# iNNOVULIS™ Human-Centric Intelligence Hub · v0.1

**Artificial Human-Centric Intelligence Central Integrated Hub.**

Mission: a unified framework for improved human health innovations.

**The machine computes. The individual decides.**

This executable prototype composes the existing, auditable `paper-console/paper_console` and `paper-console/integrations/innovulis_receipt` components. A locally generated synthetic equipment threshold is signed using *ephemeral demo keys*, checked by the original independent ipQR v1.0 verifier, stored as a source-labeled hash-linked SQLite event, represented as a screen QR and optional ESC/POS bitmap preview, and can receive a separate voluntary *reading* acknowledgment from a human.

**Clinical use is prohibited.** No diagnosis, human health input, actual patient data, independent professional certification, physical sensors, calibrated joules, silicon signing, 3D material PUF, live NFC, physical printer or FPGA is used. A cryptographic success under a demo trust anchor is NOT physical or medical truth. The demo's signer, witnesses, revocation issuer and log issuer are generated by one process and do NOT constitute independently operated external witnesses.

## Reproduce

From the repository root, Python 3.11+:
```bash
python -m pip install 'cryptography>=41' 'fastapi>=0.97' 'uvicorn>=0.21' 'qrcode>=7' 'Pillow>=9' 'numpy>=1.24' 'msgpack>=1' 'pytest>=8' 'httpx>=0.25' 'pyzbar>=0.1.9' 'opencv-python-headless>=4.8'
python -m pip install --no-deps -e ./paper-console
python -m pip install --no-deps -e ./human-hub
export PYTHONPATH="$PWD/paper-console/integrations"
python -m pytest -q human-hub/tests
python -m human_hub demo --ack-synthetic --out human-hub/evidence/demo
export HUB_OPERATOR_TOKEN="$(python -c 'import secrets;print(secrets.token_urlsafe(32))')"
python -m human_hub serve --db human-hub/evidence/hub.sqlite3 --port 8781
```
Open **http://127.0.0.1:8781/** on the same machine. Do not expose this prototype to the internet. Put the operator token in the local input only; never commit it. The local demo writes a scanned-QR-compatible PNG, an **unprinted** ESC/POS raster preview, and a JSON scope record.

The full local release package also contains extended adversarial tests and a real subprocess HTTP smoke. The GitHub PR acceptance suite confirms the same core trust boundary on a clean runner. The SQLite journal is NOT globally immutable, and offline revocation is bounded by snapshot currency.

Do not merge without explicit approval. Healthcare deployment requires a clinical intended-use definition, privacy/security controls, independently trusted identities, calibrated physical measurements, quality/risk management, and independent external assessment.
